# Guía de sesiones

Plan orientativo para cada lunes (15:30–18:30). La pausa se hace hacia las 17:00.

## Sesión 1 · 28 sep · UD1

!!! tip "Guion completo"
    La sesión 1 tiene su propia página con guion, preparación y materiales: [Sesión 1 paso a paso](sesion-1.md).

| Tiempo | Qué hacer |
|---|---|
| 15:30 | Presentación del módulo, calendario, evaluación y normas de entrega (página [Cómo funciona el curso](../curso/funcionamiento.md)) |
| 15:50 | **Evaluación inicial** en Moodle (20 min) |
| 16:10 | Teoría: tipos de app y comparativa ([UD1 §1](../ud1/index.md#1-tipos-de-aplicaciones-moviles)). Dinámica: el caso de la cadena de tiendas, por parejas, 5 min |
| 16:40 | Cómo funciona una híbrida: WebView + puente + plugins (§2) |
| 17:00 | Pausa |
| 17:10 | **Instalar el entorno** con la guía. Objetivo de la sesión: que todos vean `ionic -v` |
| 17:50 | Demostración: una web de tres líneas convertida en app con Capacitor (§7) |
| 18:10 | Presentar A1.1 y empezarla |

!!! tip "Lo que suele fallar"
    Android Studio sin SDK, PowerShell bloqueando scripts, cables de carga que no transmiten datos. Ten móviles de préstamo.
