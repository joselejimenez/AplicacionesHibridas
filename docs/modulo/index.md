# El módulo

**Aplicaciones Híbridas** es un módulo **propio de centro** (horas de libre configuración) del segundo curso del ciclo de Grado Superior de Desarrollo de Aplicaciones Multiplataforma (DAM) en el IES Rafael Alberti de Cádiz.

| **FFEOE** | Del 16 de febrero al 14 de mayo de 2027 |
| **Tecnología** | Flutter + Dart ([por qué](decision-tecnologica.md)) |
| **Alumnado** | ~18-20 años, con Java **o** Kotlin de 1º, y Compose (DI) y Android (PMDM) en curso |

## Qué NO damos aquí (y por qué)

El ciclo tiene tres módulos que tocan el desarrollo móvil. Para no repetir teoría, este módulo **parte de lo que ya se ha dado** en PMDM y DI y se centra en lo que solo se ve aquí: **arquitectura multiplataforma** y **desarrollo con Flutter**. El detalle está en [Coordinación con PMDM y DI](coordinacion.md).
