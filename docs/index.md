# Aplicaciones Híbridas

**2º DAM · IES Rafael Alberti (Cádiz) · Curso 2026-2027**

Este curso vamos a construir apps que funcionan en Android, iOS, web y escritorio **desde un único código fuente**, usando **Flutter** y su lenguaje, **Dart**.
