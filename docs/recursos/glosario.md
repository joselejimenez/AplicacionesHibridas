# Glosario

AAB (Android App Bundle)
:   Formato de publicación que exige Google Play. Google genera a partir de él el APK adecuado para cada móvil.

APK
:   Fichero instalable de Android.

API REST
:   Servicio web que responde a peticiones HTTP (`GET`, `POST`, `PUT`, `DELETE`) con datos, normalmente en JSON.

Bundle
:   Conjunto de ficheros JavaScript y CSS que genera la compilación y que descarga la app.

Capacitor
:   Herramienta que empaqueta una app web como app nativa de Android e iOS y le da acceso al hardware mediante plugins.

Componente
:   Pieza reutilizable de la interfaz con su plantilla, estilos y lógica.

CORS
:   Mecanismo de seguridad del navegador que bloquea peticiones a otro dominio si el servidor no las autoriza.

Databinding
:   Conexión entre los datos del componente y la plantilla.

E2E (end to end)
:   Prueba que simula a un usuario real recorriendo la app completa.

Firestore
:   Base de datos NoSQL en la nube de Firebase, organizada en colecciones y documentos.

Fixture
:   Datos de ejemplo guardados en un fichero para usar en pruebas.

Híbrida (app)
:   App hecha con tecnologías web que se ejecuta dentro de un WebView en una app nativa.

Inyección de dependencias
:   Mecanismo por el que Angular entrega a cada componente los servicios que pide con `inject()`.

Interceptor
:   Función que se ejecuta en todas las peticiones HTTP, por ejemplo para gestionar errores o añadir cabeceras.

Ionic
:   Biblioteca de componentes de interfaz con aspecto de app móvil.

Keystore
:   Fichero con la clave privada que firma la app. Sin él no se pueden publicar actualizaciones.

KPI
:   Indicador medible de rendimiento o calidad (tiempo de carga, tamaño del bundle…).

Lazy loading
:   Cargar una parte de la app solo cuando se necesita.

Mobile-first
:   Diseñar primero para móvil y ampliar después para pantallas grandes.

Observable
:   Flujo de datos asíncrono de RxJS al que te suscribes para recibir valores.

Plugin
:   Paquete de Capacitor que da acceso a una función nativa (cámara, GPS…).

PWA
:   Aplicación web instalable que puede funcionar sin conexión.

Servicio
:   Clase con lógica o datos compartidos entre componentes.

Signal
:   Valor reactivo de Angular que avisa a la vista cuando cambia.

Standalone
:   Componente que declara sus propias dependencias sin necesidad de `NgModule`.

TestBed
:   Utilidad de Angular para crear componentes y servicios en un entorno de pruebas.

Vitest
:   Framework de pruebas que Angular usa por defecto en los proyectos nuevos.

WebView
:   Navegador integrado en una app nativa, sin barra de direcciones.

Zoneless
:   Modo de Angular sin Zone.js, en el que los signals indican qué hay que actualizar.
